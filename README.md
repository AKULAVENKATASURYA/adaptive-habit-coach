# 🌱 Adaptive Habit Coach

## Overview

Adaptive Habit Coach is a simple Flask web application that helps users stay consistent with their daily habits.

Unlike traditional habit trackers that only track completed tasks, this application asks users why they skipped a habit and provides encouraging adaptive suggestions.

---

## Features

- 🏠 Landing Page
- 📋 Dashboard
- ✅ Mark Habit as Completed
- ⏭ Skip Habit
- 💡 Adaptive Coaching Suggestions
- 🌱 Daily Motivation

---

## Technologies Used

- Python
- Flask
- HTML
- CSS

---

## Installation

Clone the repository:

```bash
git clone https://github.com/AKULAVENKATASURYA/adaptive-habit-coach.git
```

Install Flask:

```bash
pip install -r requirements.txt
```

Run:

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```
